# JavaScript 2: Social Media Application

This is my submission for my course assignment Javascript 2: A social media application. Koble allows users to go through posts, create posts, register and log in, view own profile and other profiles, and follow/unfollow users.

## Live Demo

- [**Live Site**](https://synnestorm.github.io/ca-javascript)
- [**Github Repository**](https://github.com/synnestorm/ca-javascript)

## Description

In this assignment, I was tasked to build the front end of a social media application using JavaScript and a provided API. The application must allow users to register, log in, view posts, and perform CRUD operations on their own posts. It must also include features such as viewing profiles, following or unfollowing users, commenting on posts, and reacting to a post with an emoji.
